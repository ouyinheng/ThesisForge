# 首页工作台（Dashboard）UI 设计

> 适用页面：`HomePage.vue`（路由 `/`）
> 设计目标：打开应用即进入一个信息密度适中、操作直达、视觉克制的工作台。
> 设计语言严格复用项目现有 Design Token（见 `src/styles/main.less`），确保与编辑器、阅读页、掘金页风格统一。

---

## 1. 设计原则

| 原则 | 说明 |
| --- | --- |
| 主色克制 | 仅按钮、激活态、强调数字、链接使用 `--color-primary`（`#D12F2F`），其余用中性灰 |
| 字体分层 | 标题用衬线 `--font-serif`（编辑/阅读语境），正文/控件用无衬线 `--font-sans`，数据用等宽 `--font-mono` |
| 阴影克制 | 仅悬浮（hover）、弹层、卡片抬升使用 `--shadow-sm` / `--shadow-md` |
| 间距节奏 | 一切间距取自 4px 基准变量 `--sp-1`~`--sp-7` |
| 圆角一致 | 小控件 `--radius-sm`(6px)、卡片 `--radius-md`(10px)、大容器 `--radius-lg`(16px) |
| 响应式优先 | 桌面三列栅格，平板两列，移动单列 |

## 2. Design Token 速查

```
--color-primary:        #D12F2F   (主色 / 强调)
--color-primary-hover:  #B91C1C
--color-primary-light:  #FEE2E2   (浅底激活态)
--color-text:           #1a1a2e   (主文字)
--color-text-secondary: #4a5568
--color-text-tertiary:  #718096
--color-bg:             #ffffff
--color-bg-secondary:   #f8f9fb   (卡片底)
--color-bg-tertiary:    #f1f3f7   (悬浮底)
--color-border:         #e2e8f0
--radius-sm/md/lg:      6 / 10 / 16 px
--shadow-sm/md:         0 1px 3px / 0 6px 20px (低透明度)
--fs-xs → --fs-2xl:     12 → 32 px
```

暗色模式由 `[data-theme='dark']` 自动切换，组件仅引用变量，无需单独设计。

### 栅格规则
- 主区内容最大宽 `1100px`，居中。
- 数据概览：4 列等宽栅格（`repeat(4, 1fr)`，gap 16px）。
- 中部：两列栅格（`1fr 1fr`，gap 20px），左=快捷创作+工具箱，右=最近文章。
- 下部：两列栅格，左=写作活跃度，右=每日一言。
- 断点：`≥1100` 三/四列；`700–1100` 两列；`<700` 单列堆叠。

## 4. 模块详细设计

### 4.1 HERO 欢迎区
- 左侧：衬线大标题问候语（早上好/下午好…，`--fs-2xl` 36px）+ 日期（`--fs-xs` 三级灰）+ 实时时钟（`--font-mono` 24px，主色）。
- 右侧：天气卡片（浅底 `--color-bg-secondary`，圆角 `--radius-sm`），点击循环切换城市；含天气图标（主色）、温度、城市·天气、区间温度+湿度。
- 分隔：底部 1px `--color-border`。

### 4.2 数据概览（4 卡）
- 每张：左侧主色图标（`--size 24`，opacity 0.8）+ 右侧数值（`--font-mono` 24px 600）+ 标签（`--fs-xs` 三级灰）。
- 底 `--color-bg-secondary`，hover 抬升到 `--color-bg-tertiary` + `--shadow-sm`。
- 指标建议：文章数、标签数、总字数、本周发布（或“草稿数”）。

### 4.3 快捷创作（Primary Actions）
- 三个主操作按钮，采用 naive-ui `NButton`：
  - `＋ 写文章` → `/editor`（primary 实色）
  - `📚 论文` → `/papers`（tertiary）
  - `🪜 掘金阅读` → `/juejin`（tertiary，图标 `CompassOutline`）
- 下方分隔线，接「工具箱」。

### 4.4 工具箱（6 宫格）
- 3×2 图标按钮网格（移动端 2 列），每个按钮带 `--accent` 主题色（见下表），hover 时边框+文字变主题色。
- 工具项与现有 `quickTools` 一致，可点击触发对应工具面板/路由：

| 名称 | 图标 | 主题色 | 说明 |
| --- | --- | --- | --- |
| Markdown | CodeOutline | `#1976d2` | 标记语言 |
| 图片转PDF | ColorPaletteOutline | `#d32f2f` | 文档生成 |
| 字数统计 | CalculatorOutline | `#388e3c` | 文本分析 |
| JSON格式化 | FlashOutline | `#f57c00` | 数据美化 |
| URL编码 | GlobeOutline | `#7b1fa2` | 链接处理 |
| 正则测试 | SparklesOutline | `#00796b` | 表达式调试 |

- 每个图标按钮用 `NTooltip` 显示中文描述（与编辑器工具栏一致做法）。

### 4.5 最近文章（Recent）
- 列表项：标题（单行省略）+ 更新日期（`--fs-xs` 三级灰，右对齐）+ 前 2 个标签（`NTag size=tiny`）。
- 整行可点击 → `/article/:id`；hover 标题变主色、行底变 `--color-bg-tertiary`。
- 空态：居中提示「暂无文章，[前往创作]」（文字按钮主色）。
- 建议列表数：5 条（当前 3 条，可扩展）。

### 4.6 写作活跃度（热力图 / 日历）
- 用 GitHub 风格方格热力图（7 列×N 行），颜色深浅表示当日写作字数。
- 主色系渐变：`--color-bg-tertiary`(0) → `--color-primary-light` → `--color-primary`(高)。
- 底部「查看全部 →」链接主色，跳转 `/papers`。
- 若无数据，显示占位提示。

### 4.7 每日一言（Quote）
- 左侧主色竖线（`border-left: 3px --color-primary`），浅底 `--color-quote-bg`。
- 引用文字衬线 `--font-serif` 15px；作者右对齐三级灰。
- 内容按日期取固定一句（现有 `todayQuote` 逻辑），可加「换一句」按钮（随机）。

### 4.8 Footer
- 单行：`本地已保存 N 篇` · 同步状态点（绿=已同步）· 版本号 `v1.x.x`。
- 三级灰小字，居中或左对齐。

---

## 5. 交互与动效

- 所有可点击卡片/按钮：hover 200ms 过渡（`--transition`）。
- 实时时钟每秒更新（现有 `setInterval`）。
- 天气点击切换城市并写入 `localStorage`（现有 `switchWeather`）。
- 工具箱 tooltip：`trigger="hover"`、`placement="bottom"`、无箭头（与编辑器工具栏一致）。
- 跳转统一用 `vue-router`（现有 `goWrite/goPapers/goJuejin/goArticle`）。

## 7. 与现有实现的关系

当前 `HomePage.vue` 已实现：HERO（问候+时钟+天气）、3 卡数据概览、快捷操作+工具箱、最近文章（3 条）、每日一言。
本设计在之上建议的增强点：

1. 数据概览由 3 卡扩为 4 卡（增「本周发布/草稿数」）。
2. 中部加入「写作活跃度热力图」模块，强化“工作台”归属感。
3. 最近文章列表由 3 条扩展为 5 条，并补充空态引导。
4. 每日一言增加「换一句」交互。
5. 增加 Footer 状态条（存储/同步/版本）。
6. 统一所有图标按钮的 `NTooltip` 国际化（复用 `useI18n`）。

所有视觉变量、图标（ionicons5）、组件（naive-ui）均来自项目现有依赖，无需引入新资源。
